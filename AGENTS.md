# Repository guidance

Between Us is the existing application described in README.md. Its backend remains Java/Spring Boot; the TypeScript/NestJS starter next to this repository is a separate project, not a migration instruction for this app.

For Google Play listing screenshots, icons, feature graphics or preview video preparation, read [skills/play-store-assets/SKILL.md](skills/play-store-assets/SKILL.md). This is a project-local skill; agents without automatic discovery can load that file explicitly. Use synthetic data and actual app captures. Local asset generation does not authorize Play Console or YouTube publishing.
